# 04 · Guía de contenido

El juego es **un souls-like sin elementos sobrenaturales ocultos**. El mundo es duro, oscuro y
desafiante por razones humanas y naturales: guerra, ambición, hambre, enfermedad. **Todos los enemigos son humanos.**

Esta guía se aplica a **todo**: mecánicas, nombres, textos, modelos 3D, iconos, música.

## ❌ Lo que NO entra

| Categoría | Ejemplos a evitar |
|---|---|
| Magia y hechicería | Hechizos, conjuros, bastones mágicos, "milagros", encantamientos, runas con poder |
| Demonios y espíritus | Demonios, fantasmas, espíritus invocables, no-muertos, zombis, esqueletos animados |
| Brujería y ocultismo | Brujas, pentagramas, rituales, sacrificios, símbolos ocultistas, calaveras decorativas rituales, cartas de tarot, adivinación |
| Inmortalidad del alma / resurrección mística | "Almas" como moneda, resucitar por un poder sobrenatural, reencarnación |
| Deidades falsas / idolatría | Dioses del juego, rezar a estatuas, templos paganos funcionales, "gracia divina" |
| Otros | Vampirismo, licantropía, maldiciones, amuletos de "suerte" o protección |

## ✅ Sustitutos (cómo mantenemos la sensación souls sin lo anterior)

| Elemento souls clásico | Nuestra versión |
|---|---|
| Hoguera / Lugar de gracia / Ídolo del escultor | **Campamento** (fogata + tienda): descansas, curas, subes nivel, reaparecen enemigos |
| Almas / Runas / Sen | **Experiencia** (se pierde al morir, se recupera volviendo al lugar) + **Monedas** (no se pierden) |
| Frasco de Estus | **Vendajes / Ungüento de hierbas** (cargas limitadas, se recargan en el campamento) |
| Hechizos e Inteligencia/Fe | Fuera. Atributos solo físicos: Vigor, Temple, Fuerza, Destreza |
| Herramientas prostéticas (Sekiro) | **Armas secundarias mecánicas**: ballesta de muñeca, bombas de humo/pólvora, cuchillos arrojadizos (sin gancho) |
| Cenizas de guerra / Artes | **Técnicas de combate**: movimientos aprendidos de maestros (estocada, barrido, guardia rota) |
| Invocar espíritus | Sin invocaciones. Como mucho, un aliado humano en un jefe concreto por historia |
| Resurrección (Sekiro) | **relato narrado** (D1): al morir, el narrador dice "No… no fue así" |
| Jefes demoníacos | Generales, campeones, duelistas, máquinas de asedio pilotadas, guerreros enormes |

## Tono y violencia

- Combate con armas (es el núcleo del género), pero **sin gore**: sin desmembramientos ni
  decapitaciones. Sangre mínima estilo Sekiro (D2), con opción de solo chispas.
- Los enemigos humanos tienen motivos humanos: desertores, mercenarios, fanáticos de un
  *general* (no de un dios), supervivientes desesperados.

## Checklist rápida para cualquier asset o texto nuevo

1. ¿Tiene símbolos, brillos o efectos que sugieran magia? → modificar o descartar.
2. ¿Es un ser que no existe en la naturaleza (demonio, espectro, no-muerto)? → descartar.
3. ¿El texto habla de almas, dioses, maldiciones, destino místico? → reescribir.
4. ¿Un efecto visual (partículas) podría leerse como hechizo? → usar chispas, polvo, humo, fuego físico.
